# CyberStrikeAI 分析报告

- **能力范围**：全流程
- **SRC 适用度**：高——内置源码审计/组件情报/零日发现技能，配合 Burp/浏览器插件做认证态流量重放与验证码识别，提示词含赏金心态($500+标准)，直击 Web 类 SRC；但 C2/WebShell 等重器对 SRC 冗余。

## 核心思路
以 CloudWeGo Eino 多智能体编排为核心，把自然语言渗透意图转化为由 MCP 工具链+RAG 知识库驱动的侦察→利用→后渗透→报告/修复的自动化闭环攻防执行。

## 架构
Go+Eino 单体，支持 Deep/Plan-Execute/Supervisor 三种多 agent 编排及可视化图工作流；100+ YAML 工具经 MCP(stdio/HTTP/SSE/联邦)调用，带熔断与输出治理；SQLite 持久化+RBAC+人工审批+审计；项目黑板与漏洞库分离，攻击链图谱+回放，内置 WebShell/C2。

## 技术面
黑盒扫描/利用工具链(100+ nmap/sqlmap/nuclei/metasploit)；白盒源码审计与二进制逆向(source-code-hunting/ghidra/gdb)；RAG 知识库(查询改写→向量检索→重排)；MCP 多协议集成与联邦(含 Burp/浏览器插件流量重放)；视觉模型识别验证码/截图。

## 短板
依赖本地装齐 100+ 工具，部署运维重；长会话摘要致子代理失忆(靠黑板+交接包缓解)；结果验证仍靠模型判断；多 agent 高并发 token 成本高；C2/WebShell 偏内网授权渗透对 SRC 冗余并增合规负担。

## 值得神策借鉴
项目黑板(事实)与漏洞记录分离，边挖边落库抗上下文压缩；子代理强制交接包(目标/范围/成功标准/禁重复项)；Eino 多编排模式+图工作流+工具熔断/输出治理。
