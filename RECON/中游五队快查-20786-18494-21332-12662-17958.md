## 原始数据留档位置

原始数据位于 `/tmp/ts-old5/`，包含 `leaderboard.json`、`cheat-disclosures.json`、每队 `agent{rid}.json`、合并了前两页的 `sessidx{rid}.json`，以及每队一个 `session{rid}-{session_id}.json` 抽样会话。

重新拉取基础数据与前两页会话索引：

```bash
mkdir -p /tmp/ts-old5
base='https://tsecbench.zc.tencent.com/api/v1/leaderboard'
curl -fsSL "$base?set_id=4" -o /tmp/ts-old5/leaderboard.json
curl -fsSL "$base/cheat-disclosures" -o /tmp/ts-old5/cheat-disclosures.json
for rid in 20786 18494 21332 12662 17958; do
  curl -fsSL "$base/agent/$rid" -o "/tmp/ts-old5/agent${rid}.json"
  curl -fsSL "$base/agent/$rid/llm/sessions?page=1&page_size=50" -o "/tmp/ts-old5/sessidx${rid}-p1.json"
  curl -fsSL "$base/agent/$rid/llm/sessions?page=2&page_size=50" -o "/tmp/ts-old5/sessidx${rid}-p2.json"
done
```

抽样会话需从索引读取 `session_id`、`first_captured_at`、`last_active_at`，并将时间作为 UTC ISO `Z` 参数传入：

```bash
curl -fsSL "$base/agent/<rid>/llm/sessions/<session_id>?from=<first_captured_at>&to=<last_active_at>" \
  -o "/tmp/ts-old5/session<rid>-<session_id>.json"
```
