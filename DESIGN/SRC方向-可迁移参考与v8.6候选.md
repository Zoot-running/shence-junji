> 2026-09-23 用户裁定：榜一(21611)是题集特化改造，泛化弱；榜二(StrikeAgent/AtkBrain，开源已拆解)的可迁移项进军机；

## 一、榜一（21611）评估结论

- 针对 Tsecbench v1 做了**题集特化改造**：一题多线程竞速、题型模式匹配（license checker→写 Python 模拟器）、per-challenge harness 调度、共享黑板+意图图。
- **泛化弱**：题型模式匹配依赖"这套题的题型分布已知"；换题集即失效。可借鉴的是"黑板/图 + 短会话"的壳，不是它的内容。

## 三、两件未做的事（此前暂缓，现并入 v8.6 候选）

1. **自进化剧本库（方法级账本）**：StrikeAgent"进化编辑"90 会话——输入战果卡(outcome/stack/chain/techniques/avoid/cues)，输出严格 JSON `{lessons:[{action:upsert|retire, idea, method, route, when, do, avoid, chain}]}`，按 lesson_key 增量修订，**禁 IP/题号/URL/payload 只留可迁移 idea+method+route**。
   → 神策对应物：jisi 账本只记模型不记方法；v8.6 做"方法剧本库"（题材型/路由链/坑位），落盘+跨 run 积累。
2. **19 秒 lane 侦察波（微任务粒度）**：执行者从"30min 时间盒大任务"→"短命窄会话接力"。
   → v8.6 设计要素：一面一工人、硬时间盒（nmap 90s/ffuf 120s 级）、螺旋升圈(增长判据)、回合屏障、项目级并发闸、禁止嵌套、状态文件(shells/creds)+攻击图(负边剪枝)。

## 四、SRC 方向架构参考（用户战略：强化夜不收）

保留的中间层：**图 + 负结果 + 二次验证 + 方法论技能**（治重复与假阳性）；
砍掉的速度层：**先看题交旗、45 秒工人高频扫描、一题多线竞速**（CTF 特化）；
新增的现实约束：限速/封禁 pacing、授权边界(禁旁站/邻题)、PoC 完整链与影响面报告。

## 五、v8.6 候选整合（讨论后动）

1. 方法剧本库（自进化账本）——三之 1；
2. 微任务粒度实验（短时间盒 + 会话级状态接力工具）——三之 2；

5. 战报结构化（shells/creds 小节 + 开工必读纪律）。
