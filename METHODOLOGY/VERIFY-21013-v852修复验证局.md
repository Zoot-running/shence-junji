## 本局新机制发现（待修候选，按优先级）

1. **finish 门 vs 本地模式**（见⑦）——"不判死纪律"与"停表义务"冲突的化解：force=true 时主 agent 已显式授权停表，门应放行平台调用。
2. **409 duplicate 不回写旗仓**：轮换/旧值长期假 pending → 反复 flag-candidate 待决与误交（b-02 索引 0/1 反复"发现"）。修：submit 收到 409 时按 matched index 回写旗仓 rejected/duplicate。
3. **孤儿容器**：题 settle 回 queued 但容器仍 open → tick 空转不授予新题；xiaochang_close 手动释放即恢复（agent 对 a-02 实测）。候选：settle 关容器失败/遗漏时的补偿释放。
4. **已授予题不响应 priority 重排**（agent 观察 A）：priority 是唯一排序杆，但只影响队列、不动 granted——符合 v8.5 语义（授予不撤销），记录备查。
